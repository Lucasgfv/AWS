# Segurança do repositório

Este é um repositório público de estudos. Nunca publique:

- Access Key ID, Secret Access Key ou token de sessão;
- arquivos `.env`, credenciais da AWS CLI ou chaves SSH;
- IDs de conta, dados pessoais ou endereços que não precisem ser públicos;
- arquivos de estado do Terraform;
- capturas de tela sem revisar todas as áreas visíveis.

Se uma credencial for publicada, removê-la do arquivo não basta: revogue ou rotacione imediatamente a credencial na AWS e verifique o histórico e os logs da conta.
